🧠 TensorFlow Fundamentals & Operations
A hands-on walkthrough of core TensorFlow concepts, contrasting TensorFlow 1.x and 2.x paradigms, and demonstrating key tensor operations, broadcasting, matrix math, and activation functions. This project also benchmarks TensorFlow vs NumPy performance and simulates forward propagation in neural networks.
📌 Project Highlights
- ✅ TensorFlow 2.x: Constants, Variables, Eager Execution
- 🧮 Tensor Operations: Add, Subtract, Multiply, Log, Exp, Min/Max, Reduce
- 🔁 Broadcasting & Axis Reduction
- 🔢 Matrix Multiplication: Neural Network Layer Simulation
- 🖼️ Image Scaling via Element-wise Multiplication
- 🧲 Attention Mechanism: Weighted Sequence Embeddings
- 📉 Gradient Calculation with tf.GradientTape
- ⚡ Performance Benchmark: NumPy vs TensorFlow (CPU)
- 🧬 Forward Propagation with Sigmoid, ReLU, Tanh
- 🧠 Activation Function Comparison
🧪 Technologies Used
- Python 3.x
- TensorFlow 2.x & 1.x compatibility mode
- NumPy
- Matplotlib (imported but not used — ready for future visualization)
🚀 How to Run
- Clone the repo or copy the script into a .py file.
- Ensure you have TensorFlow and NumPy installed:
pip install tensorflow numpy
- Run the script:
python your_script.py


📂 File Structure

📚 Learning Outcomes
- Understand the difference between TensorFlow 1.x and 2.x execution models.
- Practice defining tensors, performing operations, and using broadcasting.
- Simulate neural network layers and attention mechanisms.
- Benchmark performance between NumPy and TensorFlow.
- Explore activation functions and their impact on forward propagation.
🧠 Author Notes
This project is designed for learners transitioning from basic Python to applied machine learning. It emphasizes reproducibility, clarity, and hands-on experimentation with TensorFlow's core APIs.
